# AI Study Companion 产品主线

当前优先级的唯一事实来源。2026-10-18 修订；操作指南见 [目录](README.md)，实现关系见 [技术地图](PRODUCT_TECHNICAL_ROADMAP.md)。旧阶段提案与交付证据见 [历史索引](HISTORY.md)，不再另行维护多份“下一步”。

## 产品目标

供作者长期自用、学习与作品集展示的个人 AI 助手，不以创新性或商业化为前提：

1. 可靠提醒与用户行动：定时任务、打卡、习惯和目标；系统执行不等于用户完成。
2. 专业回答：搜索、引用、公式与事实 / 推断边界，不因陪伴人格降低专业性。
3. 思考与成长：结合目标和上下文提出少而精的思考问题。
4. 主动内容：有来源、去重、解释推荐理由的新闻与书籍。
5. 连续陪伴：用户可控记忆、稳定人格、自然克制的主动联系和语音。

学习插件与娱乐是现用扩展；Docker、评测、平台壳和审计是承载能力，不替代用户体验。默认支持当前配套版本，不无限保留旧协议或过渡实现。

## 接下来按此顺序

1. R9.4 完成后，由用户启动 **R9.5 集成封版与结果复盘**，比较同口径指标、核心旅程、数据升级和支持范围，不自动新增框架。
2. 结合实际需求完善语音与移动发布：Huawei Push、签名和平台适配。真机由 [统一待办](DEVICE_ACCEPTANCE_BACKLOG.md) 集中执行，暂缓不等于通过，也不阻塞无关功能开发。
3. **Phase 5.6 发布前安全封版**：集中验证情绪支持、高风险场景、依赖诱导和专业边界；依赖严重告警、身份认证等发布风险按实际发布范围处理，不能在未具备条件时公开服务。
4. **Phase 8 作品集化**：架构、演示、安装包、维护指南和限制说明。R1净收益 / 人工质量 / 用户视觉 / 长期学习行动收益仍应明确未签收，不能靠作品集包装为全部完成。

开发期间不删除最小必要边界：凭据保护、授权、现实 / 虚构隔离、来源 / 分支版本控制和危险行为限制。共享付费预算以 [账本](PAID_TEST_BUDGET.md) 为准，¥3 不按轮重置。

## 防偏移与维护规则

每个 Sprint 先确认：改善哪项体验、用户能感受到什么、是否已有能力却仍在造框架、是否挤占紧邻主线。通常不能回答的内部工程工作应后移；用户明确指定的 R9 是维护成本收敛任务，不需要用增加功能为其辩护。

按 [R9规划](PROJECT_SIMPLIFICATION_PLAN.md) 的真实用途和消费者判定冗余，不因功能较旧就删除独立现用玩法。数据尽量无损保留；必要迁移须有退出条件，不能借重构清空生产数据库或旧浏览器存储。

当前指南维护操作、ADR维护理由、报告维护当次证据。测试按风险选择：局部变化做定向检查；依赖、跨层、部署与封版再做相应全量 / 构建 / Docker。默认合成数据，不向真实模型发送私人聊天，不把暂缓项写成通过。
