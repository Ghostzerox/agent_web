# R5.6：用户控制与跨端综合验收

2026-10-17，工程首期交付。入口：导航「记忆」→「数据控制与迁移」→「打开用户控制与跨端检查」。先点击「刷新服务端数据与开关」；页面不会在刚打开时自动导出或请求所有上下文。Web和本地React/APK继续共用服务端，不新增第二套数据库。

## 1. 控制 AI 可以自动读取什么

专业、陪伴、反思分别提供「读取长期记忆」和「含敏感记忆」开关。保存到服务端后，后续相关检索和模型调用前的Run校验都会检查；两端同时保存用版本冲突拒绝覆盖，保留未保存草稿。

- 初始默认全部开启，兼容已有行为；娱乐等不允许读取个人记忆的域不会因此获得权限。
- 关闭只影响**正式长期记忆的自动注入**，不删除记忆，不移除当前对话原文、Persona、旧回答或已审核摘要，不撤回已经发送给远端模型的请求。
- 敏感开关按记录的 `sensitivity = sensitive` 过滤，不是自动识别全部隐私；标为personal的内容仍可能包含隐私。更正/删除、清除摘要和清除来源继续用原有入口。
- 开关不是持续实时同步。另一端修改后，显式刷新；刷新未保存草稿需确认。页面断线会显示失败，不冒充保存成功或自动重发。

## 2. 查看本次用了什么

点击「查看最近20次上下文使用」：查看Run状态、原对话入口、个人记忆ID/排名/估算预算/当前存在状态、资料文档版本与行定位、摘要ID与覆盖消息数。资料原文降级有标记。

这是**送入模型请求的上下文元数据**，不是隐藏思考、事实正确性证明或完成证明。个人记忆历史版本在旧Usage表中没有记录，界面明确说明，不能拿今天正文冒充历史版本；删除后仅保留使用ID，不从旧日志恢复正文。旧资料引用按保存版本打开，已更正/删除则拒绝冒充旧版。摘要可能已清除或失效，需要到原对话核对。

## 3. 导出与预演

选择个人记忆、宫殿，以及最多10个知识集合；确认含私人内容后导出。Web下载JSON；APK走已有系统分享/保存适配器，打开分享面板不等于文件已保存成功。

文件格式 `ai-study-companion.memory-package`，schemaVersion 1，最多4MB。它包含所选正式记忆（含过期和敏感项）及读取开关、所选资料原文、所选宫殿布局/引用/联想。采用服务器一致读快照，不把页面旧缓存当最新导出；超限明确报错，请减少范围分批导出，不静默截断。

**这不是完整数据库备份。**不包含API Key/密钥、原始聊天、候选证据副本、摘要正文、任务、插件材料或复习日志；学习模块继续提供自己的材料导出。完整灾备仍用已有本机PostgreSQL备份/隔离恢复流程，密钥材料应独立保管。

这里“不包含Key”指不读取或导出凭据服务字段；如果你自己把密钥粘贴到资料正文、记忆或联想里，范围导出不会自动识别并擦除它。导出仍需按私人文件保存。

「选择记忆包进行本地预演」只在浏览器解析文件；会重新读取服务端ID/版本清单，但**文件正文不上传、数据库写入0次**。展示新ID、同ID/版本、版本冲突、缺少或待核对的引用。格式/大小/重复ID不合法时拒绝；同ID/版本不证明正文相同，单元引用仍需原插件材料和授权。

本阶段没有通用覆盖恢复按钮或后端restore接口；不能凭一个文件里的ID绕过授权或覆盖事实。下一阶段若增加实际恢复，需单独设计ID重映射、资料重复合并、引用重绑、用户确认和回滚。当前可在资料/背书已有导入入口明确导入原文；预演本身不是恢复许可。

## 4. 分段检查、重建与降级

打开知识资料原文后，点击「检查并按需重建分段」：

- 用保存原文及版本检查内容、hash、位置、分段顺序，正常则不写入，保留原分段ID。
- 不一致时，只重建这篇文档的派生分段；原文版本/正文、其他文档、复习记录和宫殿绑定不变。已有在途检索如果引用旧分段，将在调用前拒绝，请重新检索。
- 来源或解析策略不一致要求核对原文后通过「更正保存」处理，不静默改事实或批量重建全部资料。表结构缺失需正常迁移/恢复；此按钮不会擅自建表或恢复数据库。

检索发现某文档没有当前版本分段，或派生分段表不可用时，尝试**同owner、同模式、同批显式所选集合**的原文词项降级。最多100篇/1MB原文、最多1000候选，仍按原预算筛选、给版本/行引用。每次只在请求内临时分段，不增加全局副本或后台任务；范围太大或数据库断线就明确失败，不自动上网搜索私人问题。一般无匹配不是故障，不会因此转全库检索。

这不代表能自动发现任意部分分段缺失或语义污染；怀疑派生数据不完整时用显式检查/重建。向量索引尚未安装，因此不存在已完成的向量服务故障实验。

若分段表本身不可用，指定版本的原文仍可打开；页面明确标记暂不能高亮分段行位置，不伪造已保存分段。数据库本身不可用则不声称原文仍可读。

## 5. 更正和删除会影响哪些地方

| 操作 | 生效范围 | 不会自动做的事 |
|---|---|---|
| 更正/删除正式记忆 | 下一次检索、调用前版本/有效期检查；派生摘要按既有个人依赖失效 | 不撤回旧答案、远端请求、导出或备份 |
| 更正/删除知识原文 | 旧分段替换/删除、旧版本引用拒绝、宫殿提示重绑；覆盖消息确实引用该文档的摘要因根版本变化失效 | 不改写历史原消息，不把新正文静默塞进旧摘要 |
| 按需重建分段 | 仅修复指定文档派生索引；无变化不写 | 不改变原文版本，不触发付费摘要，不改宫殿来源 |
| 删除宫殿/位置 | 只删布局、引用与该处用户联想 | 不删除原文、正式记忆或插件复习记录 |
| 清除摘要 | 删除对应对话的派生摘要，保留原始消息 | 不退回已发生的模型费用 |

R5.6摘要依赖新增「所覆盖消息所引文档的当前根版本/删除状态」，只读元数据。没有资料引用的旧摘要保持兼容；已有资料引用的旧摘要会失效一次，需要用户显式生成和审核，不自动扣费。重新总结历史仍不是读取新版资料：希望回答依据新版，应重新选择资料检索或明确更正原讨论。旧派生记录可清除，不宣称所有历史副本已物理擦除。

## 6. 跨端验收与尚需你操作的部分

工程检查包括Web与本地React同时访问同一Docker API/PostgreSQL、旧版本保存冲突、草稿保留、刷新、来源更正拒绝、选择性导出/本地预演、无授权拒绝、重复复习拦截与断线状态。结果见 [R5.6报告](reports/R5_6_REPORT.md)、[ADR-069](adr/ADR-069-memory-control-and-cross-client-acceptance.md)。本地React浏览器测试不是华为手机实测，也没有假冒测试过原生分享面板。

当前真实背书跨端尝试因现有插件授权/可用性返回403而跳过；没有自动开启或新增授权。授权下的服务链路用真实PGlite+Gateway测试通过，手机需另验：

1. 安装本轮Debug APK并连接Tailscale，确认服务端在线。进入记忆页，读取/保存开关；在电脑刷新看同一版本。
2. 网页和APK同时编辑同条记忆或宫殿，先保存一端，再保存另一端，确认冲突后草稿仍在。不同端不是实时推送，需要刷新。
3. 授权并开启背书插件存储能力后，电脑导入合成短材料、手机建立宫殿并逐字训练，再回电脑查看复习日志/下次时间。另测导出分享实际保存、重新选择文件预演，以及关闭网络时显示失败而不是成功。

不需要为此开放公网、安装MySQL、付费向量服务或开启新模型测试。R5工程首期可用，不等于语义质量、学习收益、发布前安全或全部华为硬件验收已签收。
