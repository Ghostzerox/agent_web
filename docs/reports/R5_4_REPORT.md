## 已交付

聊天新增“分支摘要”：查看 → 显式确认收费生成 → 检查结构化摘要与逐字证据 → 审核 → 本页允许复用 → 清除。默认关闭，不自动调用模型，原始消息完整保留。Web/APK 共用一套组件。

默认当前分支至少16条、保留至少最近6条原文，较早覆盖在完整回答边界结束；目标/约束/决定/未决/历史陈述/不确定项有来源。生成始终读原消息，不递归总结已有摘要；相同指纹复用不重复收费，pending 阻止并发重复，失败/中断不自动重试。

数据库 owner → 分支拓扑元数据 → 祖先正文，兄弟正文不进入总结。覆盖清单绑定原始节点 ID/父链/role/status/正文 hash，公共祖先可以复用；草稿不会盖过仍有效的旧审核摘要。模式、生成模型/Base URL、策略、设置、Persona/记忆元数据变化时拒绝使用；明确更正措辞保守回退，不声称通用语义矛盾识别。

源消息编辑/删除触发清除派生文本，删对话级联清除；Model API 用真实分支重建“摘要＋未覆盖原文”，保留最新问题，再在 PromptRun 事务中复核。无可用摘要回完整历史，完整历史超限明确报错，不静默截断。

Envelope/导出记录实际 compressed、覆盖数与估算前后 Token；摘要默认导出脱敏。PromptRun 审计仅存 ID/hash/条数/估算，不复制摘要正文。旧请求不传 useSummary 则仍走原流程；旧首尾压缩器停用伪摘要，只保留空返回兼容壳。R1.3 复用此实现，没有第二套压缩器。

成功首用摘要成本 0.012352 + 0.006266 = **¥0.018618**，高于原文回答 ¥0.013384。仅当后续成本/覆盖条件相同，约2次复用摊平成功生成；计入第一次失败生成成本则约6次。它是样例推算，不是真实多次复用实验，未来缓存/输出/价格/重新摘要都改变结果。四次测试累计上界 **¥0.057700**，没有第二模型裁判或 Embedding 费用。

自动测试不证明摘要无失真。代码可验证证据确属原文，但不能证明每项总结正确、重要约束绝无遗漏；用户仍需核对。单一样例/字段检查不构成 R3 七维人工签收或 R1 生产净收益封版。
