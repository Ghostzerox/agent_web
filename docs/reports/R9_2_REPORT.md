## 2. 数据与停止支持的范围

- 生产数据核对使用只读事务，确认已有 Vault 配置且没有完整环境兜底；游戏会话 / 回合 / 检查点均为空。未读取聊天正文或密钥，已有聊天与凭据未迁移、未删除。
- 未访问或清空真实浏览器存储。agent_chat_sessions、agent_chat_messages、agent_memory_store、agent_api_* 即使存在也不再由本项目读写或上传；这不等于物理擦除。旧明文凭据如存在仍留在设备，本轮依照“不清空存储”要求不删除，需要彻底撤销时可手动清理并轮换旧 Key。
- 已应用的 34 份 up / rollback SQL 及收据表定义保留，不删迁移、不清库、不重建数据库卷。旧导入收据表不是现用导入功能。
- 不再支持旧浏览器线性 / versions 导入、环境模型凭据、remote-shell 打包、缺字段游戏快照、缺模板版本的启动请求及学习宫殿旧书签。当前配套 Web / React 客户端使用规范契约；旧 APK 不保证无限兼容。
- 保留 d20 / 轻量冒险 / 牌堆 / 规则包，不因为生产暂无存档就删除仍可用的玩法；保留原生桥、Huawei 扩展接口、并发版本、授权和幂等。
