# R3.3：各类任务提示词优化交付

日期：2026-10-15。实现与离线工程验证已完成；真实模型质量、结构化输出成功率和净费用尚未测量。

## 1. 交付

七种 Agent-backed 任务有独立稳定前缀，前台背书/解题等不再被描述成定时任务。新闻/书籍的标题与原校验器精确对齐；优化新闻证据和日期、书目与投入、思考问题、语义评分、解题深度/图片/工具证据、独立复习卡及三种游戏叙事的实际模板。

八类模板版本随真实调用记录到现有用量 JSONB 的可选元数据，旧数据兼容；无新增依赖、SQL 迁移、自主执行框架、第二模型或额外模型调用。不记录 Prompt 正文/Key，不把内部版本字段发给兼容 API。

保留原有输入/输出验证、任务执行状态、插件授权、游戏分支与状态提交。严格拼写、抽背/抽卡、RAG/摘要等没有以提示词名义提前宣称完成。细节、实现位置和试用建议见 [TASK_PROMPT_GUIDE](../TASK_PROMPT_GUIDE.md)。本轮模板为自行编写，没有复制外部模板或引入新许可依赖。
