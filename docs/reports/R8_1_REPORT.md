- 知识引用 URL 在校验器中严格匹配，R8.2 必须保留原 `/memory?document=…&version=…&line=…`；不能为视觉归属批量改写历史引用。
- 旧 `/memory?palace=learning` 目前只展开 / 预选学习用途，不是独立学习页或严格用途过滤。本次设计要求 R8.2 补齐别名解析和视图限制，不宣称当前已隔开。
- `/inbox?highlight=…` 已有生产者，`InboxManager` 当前没有消费该参数。已登记为 R8.2 兼容缺口；本次不修改功能、不宣称高亮已通过。
- 现有导航高亮主要使用同路径 / 子路径匹配，不能直接覆盖 `/reading` → 内容、`/persona` → 设置等新归属，需要后续显式解析。
- 工作台当前可以显式确认草稿创建任务；保留高级入口与原语义，不能只隐藏按钮或写“工具回归模块”就声称交互已迁移。
- 共用渲染、导出、提醒和资料服务不重建，Plugin API / 权限不变；未来打卡、地图、装备、事件没有提前实现或展示空壳。
