## 实现边界

没有新增 npm 依赖、数据库表、迁移或模型裁判；没有动真实用户数据库的恢复/清空操作。材料继续用 PostgreSQL 插件隔离存储，编辑/评分有版本检查；牌堆写进既有回合 JSON 状态，沿用会话事务。工具由用户主动选择，不能等同于模型已能自主调用所有工具，也不自动给插件新增权限。

九项工作台工具均有 Zod 输入输出、版本/作用域/副作用描述、有界结果与错误展示。手机使用下拉选择，桌面列表；当前参数采用可编辑 JSON，后续可逐项改成专用表单。计划草稿与真实创建分开，除确认提醒以外的工作台运行均无服务端写入。

游戏新增纯工具回合不调用模型；模型看不到剩余牌堆顺序，不能修改宿主 toolkit。幂等键+输入指纹保存在快照中，同请求重放不重抽，同 ID 不同内容拒绝；并发、分支与检查点恢复由隔离数据库测试覆盖。完整导出仍含用户自己的快照，不是多人防作弊系统。
