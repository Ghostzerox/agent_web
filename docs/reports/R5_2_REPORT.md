# R5.2 交付报告：个人记忆来源控制与知识资料库

- 日期：2026-10-16；范围：R5.2。
- 使用与限制：[知识资料库指南](../KNOWLEDGE_LIBRARY_GUIDE.md)；架构决策：[ADR-065](../adr/ADR-065-knowledge-library-and-source-deletion.md)。

## 已交付

- `/memory` 新增知识资料库，Web/APK 复用同一 React 界面：集合创建/改名说明/删除，文本与 UTF-8 Markdown 文件本地预读→显式上传，文档列表/打开/更正/导出正文/删除，版本/hash/标题与原文行号定位。
- PostgreSQL 新增集合、文档、当前分段三表，复合 owner 外键、sourceKey 去重、父集合→文档锁顺序与版本冲突保护。相同导入返回原文档，变化须明确更正；失败回滚，更新替换旧段、删除级联清理，不残留在线旧片段。
- 个人记忆增加内容筛选和明确来源控制：清证据但保留独立事实；永久删除事实时同事务删除候选副本；删除原对话默认留确认事实但清来源证据；关联事实一起删除需显式操作。候选审核、重复阻止、有效期和乐观版本冲突保留，语义矛盾由用户核对，不添加假 AI 合并。
- 新 `/api/v1/knowledge` 管理 API 与共享客户端；无新增依赖/外部服务/模型调用。资料当前不自动发送给 AI，查询/引用在 R5.3 接入；插件 v1 权限和现有学习/游戏状态不被扩大。
- 新迁移 `0028_knowledge_library.sql`，旧 28 份迁移保持原字节/校验。文档按分域策略记录所属模式，不能通过修改集合域绕过未来授权。
