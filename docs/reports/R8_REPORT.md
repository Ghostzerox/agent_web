# R8：模块化 UI 与导航收尾报告

日期：2026-10-18。R8.1 设计、R8.2–R8.4 工程与自动验收已完成；Docker 已更新且健康。用户视觉签收和真机仍保留。提交 / 推送由本轮 Git 记录核对。

## 交付

- 七个全局入口，不再全局列出人格 / 凭据 / 宫殿等所有功能，也不全局常驻专业 / 陪伴 / 反思快捷键。
- 目录→子页层级：任务分别进入待办、习惯、目标、统计、提醒联动、定时任务或工具；娱乐先选择世界与存档，再进入当前世界；内容与设置采用分类目录；学习增加助记宫殿与独立工具页。
- 可折叠模块菜单、世界 / 材料 / 题目列表、对话资料与上下文、Inbox 正文，以及语音 / 插件的高级工具。折叠保留编辑器状态，主要操作不必通过多层折叠才能找到。
- `/memory` 按个人事实、候选、资料、AI 导航、读取控制分视图，只有所选管理器挂载。学习宫殿按用途展示；旧 `palace=learning` 保持原 URL 和学习归属。
- 保留所有旧路径与严格版本知识引用；旧任务、对话模式、会话存档深链有效。Inbox `source` 对当前已加载结果筛选，`highlight` 定位并展开正文，不自动标读；缺失明确反馈。
- 九项工具按所属模块展示子集，仍复用原函数、Schema 与提醒确认流程；全部高级工具保留在设置，不扩大 Plugin API / scope。
- 承接上一轮未发布的 R7 模板分层与无剧透简介，本轮一起验收和发布；雾港仍为唯一正式模板。

自检发现并修正：取消历史返回时，查询监听器可能先卸载编辑器，随后才执行导航确认。改为下一事件任务读取最终 URL；知识原文监听器同步处理。修正后 Web 与本地 React 的独立返回用例均通过。初轮若干旧测试寻找旧入口名、或未展开正文，已调整为当前交互，并重新全量运行。没有通过删除失败场景来宣称通过。

Edge 在沙箱内曾因 crashpad 启动失败；改在获准环境中运行同机预览与浏览器，测试请求由合成 Mock 拦截。首轮 Next 生产构建通过，最终重建遭遇混合沙箱产物权限后在获准环境重建成功。以上环境失败不作为业务通过证据，表格仅计最终通过结果。

## 数据与兼容

`docker compose up --build -d` 成功，Web 与 PostgreSQL 健康、Worker 运行；健康接口 `database=ready`。PostgreSQL 仍挂载原 `agent-web_postgres-data` 到 `/var/lib/postgresql/data`，未重建数据库卷、未清空数据。只替换 Web / Worker 容器；测试预览在交付后关闭，不替代3000正式本机入口。

无数据库 Schema 变化，仍34份迁移；复用原 API、数据表、任务、插件授权和事务。不清空数据、不复制收件箱，不增加新模型生成服务。公开导航归属不等于服务权限；个人与学习宫殿共用服务但呈现用途不同。

本地 React hash 子页变更可响应，取消离开保留草稿与 URL；Web 保留 path/query。高级工具仍是 JSON 参数工作台，并非全套自然语言或可视化表单；来源筛选仅作用于当前 API 已加载列表，不假报全库检索 / 分页。主动生成与通知硬件行为未在本轮扩展。
