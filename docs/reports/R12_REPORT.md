### 审查中修正的问题

- 原导航通用500ms批准窗口可能放行下一次独立点击，现仅对同一目的地的Hash宿主续接放行；新操作和拒绝必须重新检查。单元测试区分续接与独立操作。
- 任务路由查询未就绪时会先挂默认行动，随后因查询换挂，快速输入可能丢失；改为查询就绪后再挂交互工作区。
- 模型初始读取可能覆盖先输入的配置；读取 / 处理期间禁用表单，失败保留输入，不自动保存或测试。
- 世界、道具、事件高级JSON未应用时不能假保存 / 生成覆盖；普通字段暂停编辑，应用 / 放弃后恢复。道具应用成功后清理原始缓冲。
- 引用检查不得把“history”等固定属性名当成对象引用；增加局部删除纯函数回归。状态修正不削弱服务端版本检查。
- 旧测试更新为新入口 / 短按钮 / 明确确认，保留SQL与实际请求后果断言。逐字检查只放行用量GET，不允许模型生成；记忆读取以初始Strict Mode读取次数为基线，仍断言冲突后不偷偷重读或丢草稿。
