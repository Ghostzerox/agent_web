# R5.5 交付报告：模块记忆特化与记忆宫殿 MVP

日期：2026-10-16。起点 `641aeb78e23cf976a14859599ca2c0bb8da61e2c`，分支 `codex/r3-r5-capability-plan`。本轮实现首期功能并做自检/审查/测试；华为真机和真实学习收益不由自动测试代签。

## 现在可以做什么

- 记忆页展开「记忆宫殿」：创建宫殿/房间/位置，绑定已确认事实或同模式资料，填写/编辑联想、排序、查看原文和个人记忆实际回答使用记录。
- 更正/过期/删除的来源不再返回旧正文；明确核对后重绑。删布局只删引用与联想，不误删原始资料和复习记录。
- 背书复习库→宫殿入口：材料/确认单元→位置联想→路线/可复现随机/弱项/到期抽测→逐字错漏→原有复习记录/下次复习时间。答案默认隐藏，但用户可主动查看，不是防作弊考试。
- 宫殿训练固定逐字检查，**0模型调用**，仍走原插件授权/额度/存储；不新造评分库或自动提醒。未授权/撤销/停用/额度不足不能绕过读取，重复或并发提交由材料版本拦截。

完整使用与模块矩阵：[指南](../MEMORY_PALACE_GUIDE.md)。设计：[ADR-068](../adr/ADR-068-module-memory-and-palace.md)。网页刷新后在「记忆」使用；APK需安装本轮新包。

## 特化究竟改了什么

`moduleProfiles.ts`集中登记9个业务域的关注点、权威来源和入口。专业个人预算仍5条/约500 Token；陪伴4/400，反思4/450。已相关候选中陪伴偏好/画像+8、事实+4；反思目标+10、事实+2；相关性为0仍为0，不扩大TTL/owner/敏感性权限。默认值是保守设计，不冒充测量最优。

`memoryRepository`实际检索携带consumer和预算；`conversationSummaryApi`按**服务端保存的模式**调用专业证据、陪伴时间线、反思行动或娱乐虚构隔离摘要指令。分域策略升 `memory-domain/r5.5-v1`，摘要升 `branch-summary/r5.5-v1`。R5.4旧摘要不复用但可留表并清除；原历史保留，不自动重新收费生成。

新闻时间/来源去重、阅读画像/反馈、Task/Run/Inbox、背书/解题插件、GameSession分支/角色/检查点继续复用已有可信状态，不套用统一聊天摘要。不同知识预算沿用R5.1；宫殿可整理同域资料，**独立工作流仍未自动绑定知识库RAG**。辅助7域沿用原策略，不为此添加模型调用或私有记忆权限。

## 实现与数据格式

| 层 | 代码/职责 |
|---|---|
| 策略 | `web/lib/memory/moduleProfiles.ts`、`domainPolicy.ts`、`memoryRetrieval.ts`；摘要模板 `lib/conversation/summary.ts` |
| 宫殿契约 | `web/lib/memory/palace.ts`：严格操作格式、purpose/room来源边界、唯一ID/来源、容量和路线 |
| 数据访问 | `web/lib/repositories/memoryPalaceRepository.ts`：owner/版本事务、来源修订校验、授权学习适配与练习 |
| API | `/api/v1/memory-palaces/[[...path]]`：list/create/get/patch/delete、catalog、loci来源、route、review；no-store/请求ID |
| UI | `MemoryPalaceManager.tsx` + `memoryPalaceClient.ts`，记忆页与背书入口；Web/本地React共享 |
| SQL | `0031_memory_palaces.sql` / rollback，仅新增一表+owner索引，旧迁移字节不变 |

每宫殿owner/标题/用途/rooms JSONB/version/updatedAt，位置只存source ID/单元ID/修订hash和用户联想，不存来源/答案副本。最多10宫殿、6房间/宫殿、24位置/房间、128KB布局、30KB修改请求。学习来源指纹覆盖sourceText+cue+content+unitID，不覆盖复习状态，避免一次练习让整条路线失效。

布局与插件服务不是分布式事务：先读可信房间快照/授权来源，在短布局事务中CAS确认同一版本；实际查看、训练与评分再次校验。路线每材料每请求仅一次授权读取，不跨请求缓存；评分复用插件CAS。撤销不能撤回已读客户端正文，材料删除后用户手写联想也不会自动消失，指南明确此边界。
