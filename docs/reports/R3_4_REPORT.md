## 4. 实际发现与下一步

以下没有在本轮默默修复，也没有因为整体通过率够高而忽略：

1. **书籍引用格式**：新版 `books-3/4` 各一次使用 `[^S1]` 脚注，而契约是 `[S1]`，被正确拒绝；还出现把“两本已足够”误说成数量不足的说明。应明确简短正例和禁止脚注/内部校验文案，保持引用验证，不以放宽校验掩盖问题。
2. **解题 JSON/LaTeX**：`problem-solving-5` 的一次新版回答含未正确转义的反斜杠，JSON 解析失败。应评估已确认支持的 Provider 的 JSON 输出能力与数学字符串契约，不默认所有兼容端点支持，不增加付费自动修复循环。
3. **反思筛选**：新版 `reflection-5` 一次有候选但全被现有质量规则过滤；应复盘相关性/负面禁区主题的词面规则，区分提示词缺陷和筛选器误杀，补针对性回归。
4. **学习语义反馈**：试跑/中断批次中，同义复述曾被过度挑错；格式合法仍不代表评分、限定词判断和科学事实正确。需增加等义表达正例与严肃复测，不将模型分数当客观测量。
5. **游戏节奏抽查**：无角色卡时，新版有过把建卡当行动前置的回应；服务允许这种场景，需进一步验收主持节奏与玩家控制，而非仅看补丁可解析。

人工七维评分和关键失败签收保持 `not-reviewed/null`。盲评表、N/A 理由、3.2/80%/3.0 下限与逐维退化检查已具备，但没有伪造满分。闭集/非思考/小样本不能代替真实新闻书目、图片、长对话、默认思考模式和用户“人味”体验。

因此下一步是 **R3.4 问题修正与语义验收收尾**，之后再进入 R4.1。R4/R5、R1 费用/摘要收益、R2 视觉、华为通知/真机及发布前 Phase 5.6 不因本轮交付而取消。命令和复跑约定见 [PROMPT_QUALITY_AND_COST](https://github.com/Ghostzerox/agent_web/blob/ebaeecbf67dfc03e34065d25e68d51f005177095/docs/PROMPT_QUALITY_AND_COST.md)。
