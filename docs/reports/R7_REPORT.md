## 数据与兼容

- 复用后端 PostgreSQL `game_turns.state_snapshot` 的 JSONB 扩展，未新增 SQL 迁移，仍为 34 份；原用户数据卷保留。
- 复用事务 appendTurn、会话 CAS、树形 parent 和检查点；失败动作不提交，重放回执不重复奖励。普通 NPC 变重要角色不改身份 ID，角色知识不跨兄弟分支。
- 静态模板仅在服务端，普通返回和导出不携带未揭示的家信、碑文全文或整个世界目录。公共 preset 与隐藏 catalog 分离；移动产物未包含隐藏设定文本。
- Plugin API v1、旧 d20 与 JSON export v3 保留，探索模板单独声明宿主兼容版本。探索导出不是自动恢复接口；未实现旧局一键迁移、第三方模板上传或无限实时世界。
