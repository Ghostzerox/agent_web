# R4 工具与复用矩阵

工具不是自由执行代码的入口。确定性计算优先在 Web/APK 共用的 TypeScript 执行；数据库写入继续经已有 API、Repository 与插件 Capability Gateway。工作台 `/tools` 提供可编辑输入和结果，明确“未保存、未发给模型”。描述包含版本、范围、副作用、输入/输出 Zod 契约和结果字节上限。同步纯函数没有装饰性的网络超时；真实 I/O 沿用现有取消/超时机制。

| 模块 | 基线与本轮方向 | 入口/执行者 |
| --- | --- | --- |
| 自动/专业 | 复用搜索引用；新增完整四则计算、文本原句行号/偏移定位 | 工具工作台，共享纯函数 |
| 陪伴/主动 | 复用确认记忆、频率/安静时段策略、问候记录；增强话题/行动草稿 | memory、proactivity；草稿不自动联系 |
| 反思 | 复用历史去重、禁区与强度筛选；目标/证据/最小行动草稿 | reflection、工具工作台 |
| 新闻 | 复用搜索/新颖度；增强 URL 规范化、来源检查与重复预览 | 简报生成器、工具工作台 |
| 书籍 | 复用画像；书目/ISBN 归一与重复预览 | reading、工具工作台 |
| 任务 | 复用固定上海时区、once/daily/weekly；增强未来执行预览与重复冲突提示 | tasks、工具工作台；确认后现有 API 写入 |
| Inbox/通知 | 复用筛选、已读、深链、幂等任务投递及诊断；不更改“送达”事实语义 | inbox、notifications |
| 背书 | 复用隔离存储与复习记录；增强编辑/搜索、可复现抽测、严格默写、导入导出预览 | memorization；Gateway 存储写入 |
| 解题/复习卡 | 复用算术、学习记录、错题标签和确认制卡；增强本地搜索/管理 | problem-solving；沿用授权边界 |
| 娱乐 | 复用骰子/检定；增强分支牌堆/弃牌/重置、随机表 | GameSession 真实状态快照、回合请求 |
| Memory/Persona | 复用候选确认、来源、冲突、过期、导出删除和检索解释 | memory、persona；R5 的 RAG/压缩/宫殿不提前实现 |
| Voice | 复用设备音色、读出/停止；增强确定性文本分段 | voice；自定义克隆音色仍延期 |
| Plugin | 复用 v1 三能力、配额、审核与审计；暴露工具说明，不自动新增授权 | plugins、工具工作台；任意第三方执行延期 |
| API/配置/导出 | 复用凭据保护、GET models 检测、用量、Prompt 脱敏导出 | api-key、chat；不新增付费连通性测试 |
| 导航/Web/APK | 新增共享工作台路由，复用 AppLink/hash 路由、离线状态 | 同一 React 组件；不是双份业务 |
| 维护 | 新增导入校验/重复预览；只出报告，不覆盖真实数据库 | 工具工作台；全库恢复/索引重建另行授权 |

## R4.1 验收

首批两个实际流程：输入完整算式得到有界代码计算结果；粘贴材料和查询词得到原文位置。正常、无结果、非法、重复执行、不支持输入均有测试。没有额外 npm 依赖，没有新增模型调用，没有借工具入口绕过插件授权。工作台是用户工具，不代表这些函数已经成为可由模型自主调用的 function tools。

## R4.2 验收

任务编辑页可预览下一批上海时间执行点与已加载活动任务的同刻冲突；只检查未来五次窗口，不声称穷举所有冲突。工作台另有来源检查与书目 ISBN 去重。新闻/书籍真实生成前剔除不支持的 URL、同 URL 追踪变体和未来发布日期；未知日期仍明确未知。新闻原有事件新颖度与反馈去重继续复用。书单结果再检查同名重复及已读/不喜欢的标题。纯计算不加模型调用，任务/Inbox/通知的事务和送达状态不改动。

## R4.3 验收

背书材料支持标题搜索、编辑、JSON 导出与校验预览导入（确认后新建，不覆盖既有材料）。修改知识单元将重置该单元成绩，未改内容/提示保留历史，过期版本拒绝保存。单轮可选随机、未测/低分优先、到期优先或顺序抽测；固定 seed + 材料内容与版本、同一抽测时刻可复现，无重复单元，显示排序理由，结束后须主动开启新轮。

语义复述仍可调用模型；新增逐字默写完全由代码计算，大小写/标点/空白忽略项可配置。Levenshtein 差异含增删改、原文与作答 UTF-16 位置，支持 Unicode 字符，每次最多 2000 有效字符，最多展示 60 处。结果返回完整有界差异，持久复习日志仅保留前三处差异避免堆积存储；过期版本不重复写入成绩。复习任务仍是草稿，用户确认后才创建。题库增加标题/学科/错因标签搜索，沿用题目删除、学习记录、制卡与确认任务。大规模题库、完整章节标签体系、多媒体导入和复杂 FSRS 算法另列后续，不把本轮简版当成熟题库平台。

## R4.4 验收

GameSession 新增宿主管理的可选 `toolkit` JSON 状态，不迁移旧 SQL、不修改旧快照；旧存档缺失时按空工具状态读取。支持最多 8 个牌堆、每堆 100 张物理卡（同名可有不同 ID），创建洗牌、抽牌、手牌弃牌、全量重置，以及一个等权随机表流程。结果可由 seed + 算法复现，不用于赌博/加密。

工具可单独运行，保存为 `host-tools/r4-v1` 回合，不调用模型。写入复用会话行锁、版本比较和事务。每次工具请求必带 UUID 幂等键，输入指纹持久于回合快照；重复已提交请求返回既有会话，同 ID 不同内容拒绝；并发同请求按同 seed 计算且仅提交一次。冲突返回刷新提示，无自动再抽取。branch 父节点与检查点决定牌堆状态；模型补丁不得写 toolkit，模型上下文不暴露牌堆剩余顺序，只提供可见手牌、数量与本回合实际工具结果。

隔离数据库测试覆盖持久化、重复请求、并发、跨分支与读档；纯函数覆盖空输入、非法牌/数量、耗尽、重复创建和不变性。没有新增 SQL 迁移或改变现有骰子事件表；工具行为记录位于 `game_turns.state_snapshot.toolkit`，JSON/Markdown 存档导出沿用完整快照。

## R4.5 与 16 模块输入输出核对

工作台共 9 项可执行工具：行动草稿、语音预览、插件检查、导入预演、任务预览、来源检查、书目整理、基础计算、材料定位。手机使用下拉切换，桌面使用列表；JSON 输入是首期可编辑参数界面，不是自然语言自动选工具。行动草稿可逐项确认创建任务，生成本身不保存。语音、插件与数据预演都复用实际契约，不是演示假结果。

| 模块 | 输入 → 输出 | 处置/执行者 |
| --- | --- | --- |
| 专业 | 算式/材料+词 → 数值或原句行号/偏移 | 新增，共享本地函数 |
| 陪伴/主动 | 用户确认事实、频率偏好、目标 → 事实/假设分列、行动草稿、既有触达理由 | 增强+复用，不另做人格推断器 |
| 反思 | 目标/候选/历史 → 去重评分问题、完成标准/行动草稿 | 复用筛选器+新增草稿 |
| 新闻 | 搜索来源/日期/历史反馈 → 可用来源与去重解释 | 增强生成前过滤；全网事实核查器后移 |
| 阅读 | 标题作者ISBN/画像 → 归一书目、重复与校验位、排除已读 | 增强；ISBN 通过不等于真实书目已验证 |
| 任务 | once/daily/weekly+活动任务 → 上海时间执行点/同刻冲突/确认草稿 | 增强，写入沿用核心 API |
| Inbox/通知 | Run/设备/偏好 → Inbox、投递状态、诊断/深链 | 复用，不把计划发送改叫已送达 |
| 背书 | 材料/seed/策略/默写文本 → 不重复抽测、差异、日志、待确认提醒 | 增强，共享算法+Gateway 存储 |
| 解题/卡 | 题目/答案/标签 → 检索结果、数值核验、学习记录和卡片 | 复用+标题/学科/错因检索增强 |
| 娱乐 | 选中分支/牌堆操作/请求ID → 可信卡牌/随机事件、状态快照 | 增强，服务端事务；既有骰子算法不变 |
| Memory/Persona | 候选/来源/更正或删除 → 确认记忆/检索审计/人格配置 | 复用；RAG、宫殿、压缩属于 R5 |
| Voice | Markdown/设备音色 → 实际朗读文本、分段与截断、播放/停止 | 增强可视预览；克隆音色和发音词典后移，需确定 TTS Provider/格式 |
| Plugin | manifest → API兼容结果、声明能力/配额；实际授权另查插件页 | 增强诊断，v1 仍为三项能力，不扩第三方自动执行 |
| API/导出 | 配置、GET models、用量/Prompt → 服务状态、用量与脱敏导出 | 复用，不增加付费探活 |
| 导航/Web/APK | 模式路由/草稿/连接状态 → 共用页面、手机下拉、恢复提示 | 增强，跨端同一业务实现 |
| 维护 | 导出材料/已有标题 → 逐项格式/重复/冲突报告（writes=0） | 新增预演；全库恢复与索引重建后移，需备份/索引设计与独立确认 |

### 保留限制

- 游戏当前是单用户：状态快照与完整导出供用户查看，不是多人隐藏牌/防作弊服务。
- 背书日志最多 40 次并按现有 64 KiB 单条存储上限滚动保留；不截断知识正文。材料本身过大时在写入前拒绝并要求拆分，旧记录不修改。
- 没有增加依赖、Embedding、第二模型裁判、Agent 循环或付费工具重试。真实模型费用只用于本轮 R3.4 39 次定点复测。
- 自动测试不证明华为系统通知、音色满意度或真人感；华为/卓易通真机与语义体验需要用户确认。旧 APK 不会自动获得新本地页面，需安装本轮 Debug APK。

完整交付与验收见 [R3.4/R4 报告](reports/R4_REPORT.md)。
