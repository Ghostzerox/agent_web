# R4 工具与复用矩阵

工具不是自由执行代码的入口。确定性计算优先在 Web/APK 共用的 TypeScript 执行；数据库写入继续经已有 API、Repository 与插件 Capability Gateway。工作台 `/tools` 提供可编辑输入和结果，明确“未保存、未发给模型”。描述包含版本、范围、副作用、输入/输出 Zod 契约和结果字节上限。同步纯函数没有装饰性的网络超时；真实 I/O 沿用现有取消/超时机制。

| 模块 | 基线与本轮方向 | 入口/执行者 |
| --- | --- | --- |
| 自动/专业 | 复用搜索引用；新增完整四则计算、文本原句行号/偏移定位 | 工具工作台，共享纯函数 |
| 陪伴/主动 | 复用确认记忆、频率/安静时段策略、问候记录；增强话题/行动草稿 | memory、proactivity；草稿不自动联系 |
| 反思 | 复用历史去重、禁区与强度筛选；目标/证据/最小行动草稿 | reflection、工具工作台 |
| 新闻 | 复用搜索/新颖度；增强 URL 规范化、来源检查与重复预览 | 简报生成器、工具工作台 |
| 书籍 | 复用画像；书目/ISBN 归一与重复预览 | reading、工具工作台 |
| 任务 | 复用固定上海时区、once/daily/weekly；增强未来执行预览与重复冲突提示 | tasks、工具工作台；确认后现有 API 写入 |

| 解题/复习卡 | 复用算术、学习记录、错题标签和确认制卡；增强本地搜索/管理 | problem-solving；沿用授权边界 |

## R4.1 验收

首批两个实际流程：输入完整算式得到有界代码计算结果；粘贴材料和查询词得到原文位置。正常、无结果、非法、重复执行、不支持输入均有测试。没有额外 npm 依赖，没有新增模型调用，没有借工具入口绕过插件授权。工作台是用户工具，不代表这些函数已经成为可由模型自主调用的 function tools。

## R4.2 验收

任务编辑页可预览下一批上海时间执行点与已加载活动任务的同刻冲突；只检查未来五次窗口，不声称穷举所有冲突。工作台另有来源检查与书目 ISBN 去重。新闻/书籍真实生成前剔除不支持的 URL、同 URL 追踪变体和未来发布日期；未知日期仍明确未知。新闻原有事件新颖度与反馈去重继续复用。书单结果再检查同名重复及已读/不喜欢的标题。纯计算不加模型调用，任务/Inbox/通知的事务和送达状态不改动。

## R4.3 验收

背书材料支持标题搜索、编辑、JSON 导出与校验预览导入（确认后新建，不覆盖既有材料）。修改知识单元将重置该单元成绩，未改内容/提示保留历史，过期版本拒绝保存。单轮可选随机、未测/低分优先、到期优先或顺序抽测；固定 seed + 材料内容与版本、同一抽测时刻可复现，无重复单元，显示排序理由，结束后须主动开启新轮。

语义复述仍可调用模型；新增逐字默写完全由代码计算，大小写/标点/空白忽略项可配置。Levenshtein 差异含增删改、原文与作答 UTF-16 位置，支持 Unicode 字符，每次最多 2000 有效字符，最多展示 60 处。结果返回完整有界差异，持久复习日志仅保留前三处差异避免堆积存储；过期版本不重复写入成绩。复习任务仍是草稿，用户确认后才创建。题库增加标题/学科/错因标签搜索，沿用题目删除、学习记录、制卡与确认任务。大规模题库、完整章节标签体系、多媒体导入和复杂 FSRS 算法另列后续，不把本轮简版当成熟题库平台。
