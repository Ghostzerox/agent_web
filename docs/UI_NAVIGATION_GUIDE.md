# UI 与导航规范

当前为 R12 交互重构后的共享UI，沿用R8模块归属。实施与证据见[R12报告](reports/R12_REPORT.md)，立项范围见[R12规划](R12_UI_INTERACTION_REFACTOR_PLAN.md)，历史归属见[模块指南](R8_MODULE_UI_GUIDE.md)。当前优先级只看主线，不把工程通过当作作者视觉签收。

## 入口与归属

- 七个全局入口：对话、任务、学习、娱乐、内容、收件箱、设置。桌面侧栏，手机图标打开抽屉；聊天历史抽屉独立。
- 页头“功能”打开本模块面板，不再在每页正文之前重复展开一排模块导航。任务首页直接处理行动，内容首页阅读已投递内容，设置按用途分类；其他能力仍通过所属模块进入。
- 模块目录 / 当前主要任务 → 功能子页 → 次要面板；不把所有编辑器堆在首页。地图 / 装备 / NPC / 游戏史属于当前世界，打卡属于任务，学习宫殿属于学习。
- 正式路由与模块归属登记在 `lib/platform/appRoutes.ts`；Web 与本地 React 共用。当前页面数通过架构测试检查，不在多份文档复制。
- 导航不自动调用模型、不创建任务 / 游戏、不授权插件。专业 / 陪伴 / 反思深链先确认模式意图，已有消息 / 分支不因导航改写。
- 思考问题是定时内容偏好，不等于反思对话；书籍 / 简报的生成结果位于同一持久 Inbox，不复制结果系统。

## 视觉与布局

共用 `AppShell`、`Actions`语义按钮 / 确认与CSS变量，世界布局使用局部CSS Module；不新增UI依赖或Android业务页面。

- 每个操作区区分主要 / 次要 / 轻量 / 危险按钮，导航保持链接语义；短按钮旁说明影响范围和阻塞原因。
- AI调用先确认改写范围、当前模型和可能费用；普通保存不重复确认。删除与弃稿确认展示对象，不自动重试收费请求。跳转 / 刷新网页仍保留浏览器原生草稿保护。
- 用量只在当前模块有操作时显示紧凑摘要，详情在弹层，历史在模型设置；没有实际usage不填零、不显示虚假逐Token数字。
- 世界工作台桌面分组目录、手机分区选择；普通换分区保留编辑，JSON未应用时阻止换区和假保存。地点、人物、史料、档位常规增删使用表单，高级JSON仍保留。

- 中性底色、清楚的选中态 / 焦点环；主要控件约44px，手机输入字号16px，状态不只靠颜色。
- 系统字体，无额外外网字体请求。深色模式、加载、错误、权限、冲突和禁用反馈保持可见。
- 助手正文获得主要宽度，用户气泡紧凑；公式 / 表格 / 代码在内容容器内横向滚动，分数留足上下间距，不靠整页裁切掩盖溢出。
- 多行输入：Enter发送，Shift+Enter换行；输入法组合期间Enter不发送。连接提示不覆盖输入 / 发送按钮。
- 引用、世界设定、角色卡、检查点和高级工具按需展开，重要失败 / 警告不能被不当折叠隐藏。

## 折叠、草稿与返回

- 原生 `details/summary` 保持子组件挂载；收起不销毁草稿、材料或服务端事实。
- `useNavigationGuard` 比较未保存编辑与已保存基线。取消离开保留内容；保存失败不解除保护，成功后更新基线。
- 聊天草稿按会话保存在页面内存；只有最后选择的会话ID可写sessionStorage，不把Prompt / 图片 / Key持久写入浏览器。
- 离开生成中的聊天需要确认并取消对应任务，晚到回答不能写回已经停止 / 删除的会话。
- `Drawer` 用原生dialog处理背景隔离、焦点循环、Escape / 遮罩关闭与焦点恢复。Android返回先关闭弹层，再处理草稿和历史；系统行为仍按真机待办验收。
- 当前编辑器内换区使用`replaceCurrentAppPath`通知共享查询和Hash宿主，不重挂工作台；独立跳转仍检查草稿。已确认的导航只向同一目标的宿主续接放行，不给下一次点击通用500ms豁免。
- 路由用 `appHref`：Web普通路径，APK的Hash路径；查询变化和返回应与当前编辑状态同步，来源深链仍受版本与有效性检查。

## 验证与历史证据

相关浏览器用例在 `web/e2e`，检查窄屏 / 桌面、离线状态、模式确认、焦点、长公式 / 代码、草稿与子页独立挂载。本地React另测，但不代表Android / HarmonyOS手机通过；[统一待办](DEVICE_ACCEPTANCE_BACKLOG.md)保持暂缓。

`web/scripts/ui-screenshots.ts` 仅为明确的视觉比较按需运行，改前必须指向真实旧版本；`docs/ui/r2/before` / `after` 保留当时模拟证据，不代表全部业务或手机截图。自动回归截图写入忽略的test-results，不能重新生成后冒称历史证据。
