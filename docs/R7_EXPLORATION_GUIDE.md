# R7：叙事探索实现指南

## 兼容契约（R7.1）

`GameState.exploration` 是可选的 `exploration.v1` 扩展，内部 `schemaVersion: 1`；模板另用语义版本固定。旧 `game-state.v2` 规则包、d20、树形回合和 JSON export v3 不变，不对历史快照批量写回或悄悄转换规则。新玩法通过显式开启操作进入。

评级（危险 / 能力档位）、品质（物品制作）、等阶（世界位阶）使用三个独立有序字典，等级是等阶内 1–10 的有界进度，不等于成功概率或经验公式。普通移动 / 查看 / 对话不要求掷骰。

静态模板仅在服务端注册；快照只保存运行状态与已发现的公共投影，不保存主持秘密。重要性与控制者分别建模，玩家不当作 NPC。探索道具、承诺、任务和历史不接入现实 Task / Persona / Memory；真实提醒仍需原有草稿确认。

地图、库存、事件结算由宿主确定性执行；AI 只处理局部叙事 / 对话，不可直接改探索状态。快照沿父回合产生，CAS 和请求回执复用已有原子 appendTurn，检查点不删除历史。
