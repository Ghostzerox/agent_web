# ADR-067：用户审核的分支摘要，复用 R1.3 成本链路

- 日期：2026-10-16；状态：采用（R5.4 首期）
- 承接：ADR-064 分域/版本、ADR-066 检索；不另建压缩器。

## 决策

1. 摘要按需显式生成，不每轮收费重写。生成较早完整回合，近期原文/最新问题保持原样，不递归摘要。旧首尾摘录 API 停止生成伪摘要。
2. 先 owner，再拓扑元数据解析真实祖先，最后只读祖先正文；覆盖清单绑定原消息 ID、父节点、role/status/内容 hash。公共祖先可复用，兄弟回答不混用。
3. 单次限额模型输出结构化目标/约束/决定/未决/事实/不确定项和逐字来源。代码检查结构、引用与紧凑性，但不假装证明语义；draft 必须由用户审核，使用开关默认关闭。
4. 新 PostgreSQL 表保存派生摘要，源消息变更/删除触发清除；模式、策略、模型、Persona/个人记忆元数据变化使旧摘要不可用。显式更正保守回退，隐含矛盾仍需人工关闭/清除，不声称万能检测。
5. 生成占位/指纹去重防止同来源并发重复收费；失败/中断不自动重试，清除后晚到结果不写回。无有效摘要则完整原文；超输入上限明确拒绝，不静默截断。
6. Model API 与 PromptRun 调用前复核、Envelope 元数据和默认导出脱敏统一接入；摘要不写 Memory、Persona、Task 或 GameSession 状态。发布前完整安全封版任务仍独立。
7. 成本复用 `context-summary` 用量归因，失败和生成成本也计入。首轮真实测试因默认思考耗尽输出预算失败，官方 DeepSeek 的摘要改非思考+JSON，其他 Provider/普通聊天不变。

## 证据与取舍

578 项单元/集成、43 项浏览器及本地 Bundle 流程验证工程契约。一个固定真实合成对照保留关键预算/期限/未决与禁止执行限制；首次摘要使用比完整历史更贵，条件相同才可能在复用中摊薄成本。失败记录/费用不丢弃，不用估算冒充账单或生产净收益。

摘要本质有损，逐字引用不证明整句推断正确。首期需用户核对，生成后审核不能恢复在途请求；24 份/对话和 500 节点路径限制适合个人学习项目。并发多用户权限、后台摘要队列、增量语义摘要和独立游戏/学习特化不在本阶段扩张。
