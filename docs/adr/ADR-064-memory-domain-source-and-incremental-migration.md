# ADR-064：分域记忆策略与带版本的权威来源，渐进迁移而非重建 Memory

- 状态：Accepted
- 日期：2026-10-16
- 阶段：R5.1

## 背景

现有确认记忆可编辑/删除/过期，学习数据有插件隔离，游戏已有分支状态。后续资料库/RAG/摘要若把这些记录全部拼成“长期记忆”，会混入虚构剧情、旧资料和兄弟分支。现有娱乐聊天的候选提取已排除个人事实，但记忆检索尚未按真实保存模式排除，需在资料库开发前修正。

## 决策

- 复用 MemoryItem/Candidate/Usage、TaskRun、插件 v1 存储和 GameSession；R5.1 不增表/依赖/向量数据库，也不做付费摘要。
- 十六模块声明个人/知识预算、允许集合域、数据集域、分支种类与写入边界。专业/自动、陪伴、反思保持 5 条/500 估算 Token 的已确认个人记忆，娱乐不注入个人事实；未知模式默认拒绝。模式由服务端真实会话解析。
- 调用审计事务锁定会话后再次核对模式，避免检索后切换到娱乐仍提交已选记忆；旧的版本/TTL/owner 检查及 Usage 原子性不变。
- 新来源引用包含 owner、源类型/ID、scope、版本或内容 hash、生命周期/敏感性/有效期；数据层先过滤，再读取正文。知识集合/学习插件/当前树祖先由宿主解析，不接受客户端自行授予范围。
- 派生依赖直接指向权威原文，含策略和生成/索引策略版本；源缺失、变更、失效或祖先不匹配则不能复用。当前仅提供严格 Schema 和纯校验函数，实际索引/摘要生命周期分别在 R5.2–R5.4 接入。
- 已确认个人事实与来源消息分开管理；当前删除对话后事实及候选证据仍可能保留。R5.2 必须明确关联删除语义和证据副本处理，不宣称本次已完成全链路删除。
- 旧 Prompt 快照不覆盖；新增 R5.1 指纹快照，证明原 R4 80 个离线请求/样例不变。

## 后果与替代方案

不选“一次新建所有 RAG/Palace 表”：避免在尚无真实导入/检索反馈时固化空结构。后续新增表采取可回退的兼容迁移和隔离恢复演练，不搬动现有 Memory。

不选“所有模式共享个人记忆，再靠 Prompt 不使用”：数据已进入模型即无法靠文本保证隔离。运行时模式过滤只增加必要读边界，公开 API/插件权限不扩张。

引用校验不能替代认证、可信 metadata 适配器或真实索引删除。现有单用户固定 owner、敏感记忆细分控制、candidate 证据删除、资料/RAG/摘要/宫殿均明确保留；设计和量化目标见 [分域规范](../MEMORY_DOMAIN_AND_SOURCE_GUIDE.md)。

## 验证

纯函数覆盖十六模块及错 owner/集合/插件/分支、缺失或更改版本、过期/删除、策略切换和派生依赖重复。PGlite 运行真实迁移/Repository，验证娱乐排除、其他 owner 隔离、检索后模式改变及记忆更正/删除在调用前拒绝，失败事务不残留审计。Core/Prompt/浏览器回归验证既有流程；不以模拟测试宣称真实 RAG 召回率或主观质量通过。
