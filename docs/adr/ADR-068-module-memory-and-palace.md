# ADR-068：分域记忆配置与引用型记忆宫殿

- 日期：2026-10-16
- 状态：R5.5 MVP采用

## 背景

R5.1–R5.4已有分域、来源版本、资料库/词项RAG、审核分支摘要；背书/解题与游戏已有独立可信记录。需要按业务连续记忆，并让用户可视化组织来源和训练回忆，不能为宫殿另造事实/评分数据库或突破插件授权。

## 决策

1. 业务策略分开：专业5/500、陪伴4/400、反思4/450个人上下文上限；后两者只对已相关候选作偏好/目标加权。新闻/阅读/任务/学习/娱乐复用原有结构化状态与不同知识预算，不强制使用聊天摘要。
2. 摘要按服务端模式增加业务关注点并升到R5.5，失效旧摘要而不删除原文、不自动重建收费。新策略版本进入既有有效性链路；历史快照保留。
3. 单表布局JSONB存来源引用+修订指纹及用户联想。复用一套房间/位置组件，通过purpose和room.module区分来源。导航模式不产生自动RAG授权；学习目的只关联授权背书单元。
4. 单元正文/作答/间隔记录仍归背书服务，通过原Gateway授权/额度/审计访问。路线只输出提示与位置；逐字评分零模型调用，复用已有拼写检查与历史，服务端固定verbatim，材料CAS防重复提交。
5. 布局CAS与来源失效分开：先在布局事务外完成授权源读取，避免Gateway嵌套事务/长事务；事务校验布局版本。后续使用按当前源版本再验证；不承诺布局与插件存储的跨仓库分布式原子快照。路线内同材料去重读取，只在该请求内缓存。
6. 仅新增0031迁移及可回退表，不改旧SQL校验和。不加图/向量数据库、依赖、后台任务或新的模型调用。

## 取舍

MVP采用列表/顺序调整而非空间3D。宫殿本身不改善语义召回，也不能用模拟测试证明学习效果；联想由用户维护，不伪装成原文或真人经历。材料变更显式重绑可能多一步，但避免暗中用旧答案。源删除不会擦掉用户手写联想、旧备份或已打开客户端；这不等于所有副本都被清除。

## 后续

R5.6统一控制/导出/跨端/重建验收；按实际需求接模块自动资料选择、可编辑AI联想建议、增量记忆同步或Embedding。任何收费与外发资料继续受共享预算和用户选择约束。
