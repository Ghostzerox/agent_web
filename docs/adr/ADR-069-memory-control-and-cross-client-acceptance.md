# ADR-069：可控检索、范围记忆包与跨端验收

- 日期：2026-10-17
- 状态：R5.6工程首期采用，真机保留

## 决策

1. 单表 `memory_controls`（0032）保存三种个人聊天模式的检索/敏感开关和版本；默认兼容旧行为。在检索和Run记录前分别校验，开关不等于删除旧历史、Persona或摘要。
2. 现有管理、更正、删除继续复用；修复记忆编辑失败后自动刷新丢草稿的问题。开关和原文保存均用版本冲突保护，刷新丢草稿须确认。
3. 范围记忆包以显式DTO导出正式记忆、所选知识原文及宫殿，4MB上限、一致读快照。密钥、原始对话/摘要和插件材料不混入；它不替代数据库灾备。
4. 文件预演完全本地，服务端只提供ID/版本清单。没有restore写接口；同版本不证明内容相同，更不能证明恢复授权。真实恢复/跨实例ID重映射后续另设计。
5. 派生分段只按文档检查/按需重建。无变化保留ID，有变化不改根版本；派生不可用时有界同范围原文降级，虚拟分段在Run时按根hash、位置与原文片段再次校验。断开数据库不冒充成功，不联网扩散私人查询。
6. 摘要上下文指纹纳入覆盖消息的知识引用及当前源根版本/删除状态，不读取新版正文、不自动收费；没有资料引用的旧摘要兼容。历史原文和有效事实来源分开。
7. 最近请求只暴露已有使用/检索/摘要元数据，不存新Prompt正文，不伪造历史记忆版本或隐藏思考解释。
8. Web与APK共用客户端与服务端，通过合成记录的真实HTTP/PG、浏览器/Bundle、插件授权SQL链路分别验收。学习真链未授权就明确保留，不能代替用户点击授权；硬件分享/通知另签收。

## 取舍与后续

不新增全局同步框架、向量库、后台重建器或通用恢复系统。页面跨端修改需要显式刷新，原文降级上限100篇/1MB，不自动检测任意部分污染。保留Embedding、独立业务自动RAG、真实学习/陪伴质量、净成本、华为硬件/发布签名及Phase5.6封版；R5.6不是Phase5.6。
